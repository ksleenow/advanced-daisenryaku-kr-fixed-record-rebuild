# 어드밴스드 대전략 한글화 고정 레코드 재구축

일본판 원본 ROM의 구조와 표시 칸 수를 변경하지 않고 한글화하는 새 프로젝트다.
이전 재구축 프로젝트는 조사 자료로만 사용하며 빌드 입력으로 사용하지 않는다.

## 절대 원칙

- 일본판 Rev. A 원본만 기준으로 삼는다.
- 원본 레코드의 바이트 길이, 문자 칸 수, 항목 수와 순서를 유지한다.
- 짧은 번역은 공백으로 채우고 긴 번역은 원본 칸에 맞게 축약한다.
- 일본판에서 영문인 문자열은 영문 그대로 유지한다.
- 포커스 초기/선택/해제 문자열을 각각 검사한다.
- 원본 화면 좌표, 타일 번호, VRAM 업로드 범위와 실행 코드는 변경하지 않는다.
- 한 화면의 변경이 다른 화면의 ROM 바이트를 바꾸면 빌드를 거부한다.
- ROM을 배포하거나 외부로 업로드하지 않는다.

## 빌드 단계

1. 무패치 원본 왕복 빌드
2. 글꼴 코드 대응표 작성
3. 화면별 고정 길이 문자열 목록 작성
4. 한 화면씩 적용 및 초기/포커스 인/포커스 아웃/복귀 검증
5. 최종적으로 패치 파일만 제작
