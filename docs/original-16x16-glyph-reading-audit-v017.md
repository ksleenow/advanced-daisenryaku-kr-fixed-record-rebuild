# v017 원본 16x16 글리프 판독 재감사

## 범위

- 일본판 Rev. A 원본의 16x16 글리프 `0x120..0x23F`
- 기준 ROM: `R:/work/original_rev_a_probe.md`
- 비교 대상: `config/glyph-patches.json`

## 결과

- `0x123`은 `索`, `0x124`는 `敵`임을 원본 비트맵으로 재확인했다.
- 기존 오독 `秀/誠`은 v017에서 `索→색`, `敵→적`으로 정정됐다.
- 혼동하기 쉬운 다음 슬롯은 현재 원장이 맞다.
  - `0x122 優`, `0x137 去`, `0x13C 建`
  - `0x140 貫`, `0x141 費`, `0x142 徹`
  - `0x158 動`
- `0x160..0x1DF`와 `0x1E0..0x23F`의 적용 대상은 원본 렌더링과
  전부 일치했다. 추가 패치는 필요하지 않다.

## 안전성

- 이 감사 과정에서는 ROM, 글리프 설정, 레코드, 포인터, 코드 및 VRAM
  배치를 변경하지 않았다.
- 렌더링 자료는 `out/analysis/original-font-*.png`에 있으며 빌드 입력이
  아니다.
- 실행 안전 복귀 기준은 계속 v016, 현재 검증 후보는 v017이다.
