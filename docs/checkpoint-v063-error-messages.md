- ROM: `out/project-04-start16-v063.md`

- 크기: 2 MiB

## 적용 원칙

- 일본판 Rev A의 오류 레코드별 셀 수(11~18셀)를 그대로 유지했다.
- 번역문이 짧은 경우 오른쪽을 공백 셀로 채웠다.
- 번역문이 원본 셀 수를 넘으면 빌드가 즉시 실패한다.
- 원본 문자열과 공용 글리프는 수정하지 않고 확장 영역의 독립 레코드로 옮겼다.
- 일본판 실행 코드가 직접 참조하는 오류 43종의 포인터만 변경했다.
- 영문판 데이터는 변경하지 않았다.

## ROM에 남아 있으나 실행 참조가 없는 레코드

다음 여섯 레코드는 Rev A 실행 코드에서 참조되는 포인터를 찾지 못했으므로 원본 보존을 위해 수정하지 않았다.

- 오류 12 (`0x0EF744`)
- 오류 21 (`0x0EF828`)
- 오류 28 (`0x0EF8C2`)
- 오류 34 (`0x0EF93F`)
- 오류 35 (`0x0EF950`)
- 오류 44 (`0x0EFA1A`)

## 실행 검증 항목

오류 메시지는 발생 조건별로 다음을 확인한다.

1. 첫 표시
2. 동일 오류 재표시
3. 오류 해제 후 지도 복귀
4. 다른 오류로 전환
5. 지도/메뉴/사령부의 기존 표시가 변하지 않는지
