# v100 통합 프로젝트 보존 체크포인트

작성일: 2026-09-23

## 목적

- 현재까지 진행된 모든 소스, 번역 원장, 분석 도구와 실행 검증 자료를
  `v100`이라는 하나의 보존 지점으로 고정한다.
- v001~v089 파일명은 빌드 계보와 실패 원인을 재현하기 위해 변경하지 않는다.
- ROM은 저작권 자료이므로 Git/GitHub에 올리지 않고 로컬 `out/`에만 보존한다.

## 로컬 v100 ROM

- 파일: `out/advanced-daisenryaku-kr-fixed-record-v100.md`
- 승격 원본: `out/project-06-unit-names-faction-stats-v089.md`
- 크기: 2,097,152 bytes
- SHA-256: `22CC1EE5A5F6C3B67059B94AFC3ACEBC145AFE16D49F094E60D924F5D18FFCA9`
- Mega Drive 헤더 체크섬: `0x39EA`
- v089와 v100은 바이트 단위로 동일하다.

## 포함 범위

- 일본판 원본 기반 고정 길이 번역과 16x16 글리프 작업
- 별도 16x16 글꼴 뱅크와 시작/옵션/게임 메뉴 작업
- 한글화 안내, 연혁 데모와 캠페인 설명 자료
- 8x8 유닛명·병기명 조사 자료 및 실험 도구
- 게임 시작 전 국가명 `독 일 제 국` 전용 출력 경로
- 포커스 초기/선택/해제와 VRAM 경로를 조사하기 위한 추적 스크립트

## 검증된 사실

- ROM 크기는 2 MiB이다.
- SHA-256과 헤더 체크섬을 기록했다.
- 일본판 원본 ROM은 변경하지 않는다.
- `out/` 전체는 `.gitignore`로 제외되어 GitHub에 업로드되지 않는다.

## 알려진 미해결 문제

- v100은 완성판 선언이 아니라 현재 상태의 보존판이다.
- 8x8 작업 이후 일부 지도 HUD 유닛명과 성능표 유닛명의 매칭 회귀가 보고됐다.
- `39식보병` 이외의 일부 8x8 유닛명은 호출 경로별 코드표가 일치하지 않을 수 있다.
- 따라서 v100을 다음 수정의 직접 기반으로 사용할 때는 8x8 렌더러, 코드표,
  일반/반전 글꼴, 초기/포커스 인/포커스 아웃 경로를 먼저 재검증한다.
- 외부 공개 한글판은 구조 연구 자료로만 취급하며 그 ROM이나 번역 자산을
  이 저장소의 기반으로 사용하지 않는다.

## Git 보존 정책

- Git 태그: `v100`
- Git에는 소스, 문서, 설정, 해시와 검증 이미지만 포함한다.
- 원본 ROM, 완성 ROM 및 사용자 제공 저작권 자료는 포함하거나 배포하지 않는다.
