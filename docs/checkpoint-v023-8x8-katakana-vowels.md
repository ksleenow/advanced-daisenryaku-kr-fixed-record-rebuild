# v023 8x8 가타카나 모음 체크포인트

## 변경

- 부모: v019 최초 격리 8x8 체크포인트
- 출력: `out/fixed-record-8x8-katakana-v023.md`
- 원본 레코드 코드는 그대로 두고 아래 기존 8x8 슬롯의 비트맵만 바꿨다.
  - `0x49 ア → 아`
  - `0x4A イ → 이`
  - `0x4B ウ → 우`
  - `0x4C エ → 에`
  - `0x4D オ → 오`
- 각 슬롯은 순서대로 v019~v023에 하나씩 누적했다.

## 결과

- SHA-256: `DE1414F6611C1C4083663675AF68FE85F4E6C69A66E91AB5C533C27764D45DD1`
- 크기: 1,048,576바이트
- 메가드라이브 체크섬: `0x6CF8`
- 문자열, 레코드, 포인터, 코드, VRAM 배치 변경: 0
- 16x16 영역은 v018과 동일하다.
- v018 대비 8x8 변경 범위는 위 다섯 슬롯의 각 8바이트뿐이다.

## 단계별 검증

각 슬롯을 추가할 때 직전 ROM과 비교해 새 슬롯 8바이트와 체크섬 외의
차이가 없음을 확인했다. 각 단계에서 BizHawk의 지도 메뉴, 지도 하단 상태창,
개발 화면 세 상태를 불러 실행했고 캡처가 갱신되며 에뮬레이터가 응답 상태를
유지했다.

사용자 실행 검증에서는 표준 시나리오 진입, 최초 표시, 포커스 진입/이탈,
메뉴 재진입, 지도 복귀를 확인한다.
