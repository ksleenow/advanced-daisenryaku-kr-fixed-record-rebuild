# v069 한글화 안내·연혁 데모 체크포인트

## 범위

- 메인 타이틀은 최종 프로젝트까지 동결했다.
- 기존 승인 문구 `이 비극이 반복되지 않기를 바라며` 아래에 다음을 표시한다.
  - `한글화 v0.95`
  - `한글화 기술·제작 Codex`
  - `기획·제작 쏘갈장군`
- 안내 화면은 180프레임(약 3초) 유지한다.
- 일본판 실제 데모가 사용하는 연혁 8항목을 한글화했다.
  - 1919년 베르사유 조약 체결
  - 1923년 뮌헨 폭동
  - 1933년 히틀러 내각 성립
  - 1934년 힌덴부르크 사망 / 히틀러 총통 취임
  - 1936년 독일 라인란트 진주 / 일독 방공협정 조인
  - 1938년 독일 오스트리아 병합 / 뮌헨 회담
  - 1938년 주데텐란트 독일에 할양
  - 1939년 독일, 체코 해체 / 독소 불가침조약 체결
- ROM에만 남은 포츠담 선언은 실제 데모 흐름에 없으므로 추가하지 않았다.

## 안전 원칙

- 일본판 원본 영문 레코드는 변경하지 않았다.
- 기존 v029 글꼴에 검증된 한글 글리프를 우선 재사용했다.
- 부족한 글리프만 확장 은행에 추가했다.
- 연혁의 두 번째 줄은 첫 번째 줄 한글 시작 위치에 맞췄다.
- 메인 타이틀 그래픽과 문자열은 변경하지 않았다.
