# v018 16x16 일본어 글리프 완료 체크포인트

## 변경

- 부모 후보: v017
- 일본판 원본 슬롯 `0x0EE 工`을 한자음 `공`으로 1:1 치환했다.

## v017 대비 격리 검증

- 차이 26바이트
- 체크섬 2바이트와 `0x0EE` 16x16 글리프 내부 24바이트만 다르다.
- 8x8 글꼴 영역은 v017과 완전 동일하다.
- UI 레코드 `0xEF000..0xEFFFF`는 v017과 완전 동일하다.
- 코드, 포인터, 문자열 길이, VRAM 배치 변경은 없다.

## 실행 스모크 검증

BizHawk 2.11.1 / Genplus-gx에서 기존 지도 메뉴, 지도 상태창, 개발 화면
상태를 각각 로드했다. 세 화면 모두 정상 표시되었고 정지나 전체 타일 붕괴는
없었다.

이 지점을 8x8 글꼴 변경 직전의 16x16 완료 후보로 사용한다.
