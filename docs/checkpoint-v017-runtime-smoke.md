# v017 실행 스모크 검증 체크포인트

## 대상

- ROM: `out/fixed-record-kana-kanji-phonetic-v017.md`
- SHA-256: `D6579C4940A67034292996BF6D4F40A23C82CF424249EA7E07785BF3C469EDF6`
- 크기: 1,048,576 bytes
- 메가드라이브 체크섬: `0x49CE`

## 재현 빌드

- 일본판 Rev. A 원본에서 현재 글리프 그룹 전부를 다시 적용했다.
- 재현 결과와 v017 후보의 SHA-256이 동일했다.
- 바이트 차이: 0
- 레코드, 포인터, 코드, VRAM 배치 변경: 0

## 실행 확인

BizHawk 2.11.1 / Genplus-gx에서 기존 검증 상태 3개를 읽기 전용으로
로드했다.

1. 지도와 C 메뉴 표시
2. 지도 하단 상태창 표시
3. 개발 화면 표시

세 상태 모두 로드됐고 화면 전체 타일 붕괴나 에뮬레이터 정지는 없었다.
이 검증은 전체 플레이 검증을 대신하지 않으며, 사용자는 v017에서 메뉴 입력,
스탠다드 진입, 포커스 전환과 지도 복귀를 추가 확인한다.

## 도구

`tools/runtime_smoke.lua`는 ROM을 수정하지 않고 기존 세이브스테이트를
읽어 세 화면을 캡처한다. 세이브스테이트를 덮어쓰지 않는다.
