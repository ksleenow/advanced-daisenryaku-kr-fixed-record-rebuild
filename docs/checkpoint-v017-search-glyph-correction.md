# v017 색적 글리프 판독 정정

- 부모 작업본: 사용자 실행 검증을 통과한 v016
- 일본판 Rev. A 원본 16x16 폰트를 직접 렌더링해 `0x123/0x124`를
  `索/敵`으로 재확인했다.
- 기존 원장의 `秀→수`, `誠→성` 판독은 잘못이므로 `索→색`, `敵→적`으로
  정정했다.
- 출력: `out/fixed-record-kana-kanji-phonetic-v017.md`
- 크기: 1,048,576 bytes
- SHA-256: `D6579C4940A67034292996BF6D4F40A23C82CF424249EA7E07785BF3C469EDF6`
- 메가드라이브 체크섬: `0x49CE`
- v016 대비 변경: 체크섬과 위 두 16x16 글리프뿐
- 허용 범위 밖 변경: 0
- UI 레코드 `0xEF000..0xEFFFF`: v016과 완전 동일
- 8x8 글꼴 및 DMA 꼬리 `0x3850E..0x38F9D`: v016과 완전 동일
- 레코드, 포인터, 코드, VRAM 배치 변경: 0

실행 검증 항목은 색적 화면의 초기 표시, 선택 변경, 재순환, 메뉴 재진입,
지도 복귀 및 스탠다드 시나리오 로드다. 사용자 실행 확인 전에는 v016을
안전 복귀 기준으로 유지한다.
