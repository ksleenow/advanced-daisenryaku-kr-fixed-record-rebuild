# v068 데모 도입부 체크포인트

## 범위

- 자료제공 화면
  - `자료제공`
  - 일본판 원본 잡지 로고 보존
  - `월간 전차 매거진`
  - `월간 항공정보`
- 후속 문구
  - `이 비극이 반복되지 않기를 바라며`

## 구현 원칙

- 일본판 원본의 압축 그래픽과 화면 복귀 흐름을 기준으로 삼았다.
- 이전 재구축의 실행 코드는 가져오지 않았다.
- 검증된 그래픽 타일만 재사용하고, 두 설명줄을 쓰는 68000 보조 루틴은
  현재 빌더 안에서 명령어와 VRAM 목적지를 명시해 독립적으로 생성한다.
- 비극 문구는 일본판 18칸 레코드와 정확히 같은 18칸이며 원래 표시 위치와
  타이밍 경로를 그대로 사용한다.
