- 출력: `out/fixed-record-8x8-katakana-complete-v029.md`
- 기본 가타카나 `0x49..0x8A` 유지

## 실행 스모크

BizHawk 2.11.1 / Genplus-gx에서 기존 검증 상태 세 개를 읽기 전용으로
불러 새 캡처를 생성했다.

1. 지도와 C 메뉴
2. 지도 하단 상태창
3. 개발 화면

세 화면 모두 갱신됐고 에뮬레이터는 응답 상태를 유지했다. 전체 타일 붕괴나
정지는 발견되지 않았다. 사용자 검증에서는 표준 시나리오 번호, 포커스
진입/이탈, 재진입 및 지도 복귀를 추가 확인한다.

이 체크포인트로 잔여 작업 목록의 1번과 2번을 완료한다. 3번 이후는 사용자와
협의하기 전까지 진행하지 않는다.
