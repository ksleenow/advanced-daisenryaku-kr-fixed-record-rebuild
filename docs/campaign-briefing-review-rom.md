# 캠페인 설명문 연속 검수 ROM

정식 빌드의 캠페인 설명문 44개를 한 번에 검수하기 위한 별도 QA ROM이다.
일반 배포본이나 실기용 최종본으로 사용하지 않는다.

## 진입 방법

1. `CAMPAIGN`을 선택한다.
2. `STANDARD`를 선택한다.
3. 첫 번째 시나리오(시나리오 0)를 시작한다.
4. `A` 버튼으로 다음 페이지를 계속 넘긴다.

각 묶음은 `시나리오 00`부터 `시나리오 43`까지 별도 표제 페이지를 먼저
표시한다. 그 다음에는 해당 일본판 시나리오의 원래 텍스트 슬롯 수, 빈 행,
내부 페이지 전환 제어값을 그대로 재현한다. 시나리오 사이에도 원본 페이지
전환 제어값 `0x80`을 사용한다.

## 생성 파일

- 정식 ROM: `out/project-05-campaign-briefings-v072.md`
- 검수 ROM: `out/project-05-campaign-review-v072.md`
- 생성 도구: `tools/build_campaign_review_rom.py`

검수 ROM은 정식 ROM의 글꼴·번역·렌더러를 그대로 사용하고, 시나리오 0이
참조하는 압축 설명문 스트림만 QA 전용 연속 레코드로 교체한다.
