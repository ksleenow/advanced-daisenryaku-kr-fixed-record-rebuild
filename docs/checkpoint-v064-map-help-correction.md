# v064 B버튼 지도 도움말 교정 체크포인트

## 교정 내용

- 일본판 Rev A 원문:
  - `Aボタン 次部隊  Cボタン 首都`
  - `Aボタン 首都  Cボタン 次部隊`
- 한글 고정 레코드:
  - `A버튼 다음부대  C버튼 수도 `
  - `A버튼 수도  C버튼 다음부대 `
- 두 레코드는 원본과 같은 17셀이다.
- 일본판 원문에 있는 영문 `A`, `C`는 유지했다.
- 원본 문자열·공용 글리프는 바꾸지 않고 포인터 피연산자 `0x00A6A8`, `0x00A6B4`만 독립 레코드로 전환했다.

- 첫 표시와 B버튼 전환 뒤 표시를 각각 검사한다.
