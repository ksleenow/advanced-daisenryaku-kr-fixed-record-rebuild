# v024 8x8 히라가나·가타카나 모음 후보 — 폐기

> 사용자 실행 검증에서 시나리오 번호 `0..4`가 `아이우에오`로 바뀌었다.
> `0x00..0x04`를 히라가나로 추정한 대응표가 틀렸음이 입증되었으므로
> 이 ROM은 사용·배포·후속 빌드의 부모로 삼지 않는다. 복귀 기준은 v023이다.

## 변경

- 부모: v023 8x8 가타카나 모음 체크포인트
- 출력: `out/fixed-record-8x8-hira-kata-vowels-v024.md`
- 잘못 적용한 `0x00..0x04`는 실제 숫자 `0..4` 표시 슬롯이었다.
- 가타카나 `0x49..0x4D`: `アイウエオ → 아이우에오`
- 8x8 전용 대응표를 `config/small-glyph-patches.json`로 분리했다.
  16x16 인덱스가 없는 히라가나를 억지로 16x16 패치와 결합하지 않는다.

## 폐기 사유

기존 세이브 상태 스모크는 화면 전체 붕괴와 정지만 확인하므로 시나리오
목록의 숫자 변조를 잡지 못했다. 사용자가 시나리오 목록을 직접 확인하면서
오류가 발견되었다.

향후 8x8 슬롯은 시트 모양만 보고 추정하지 않는다. 실제 원본 화면과 레코드
코드 사용처가 일치한다고 입증된 슬롯만 변경한다.
